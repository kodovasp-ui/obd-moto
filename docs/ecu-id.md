# Αναγνώριση ECU — CFMOTO 450MT

Ανάγνωση: 2026-11-17 με `tools/ecu_id.py` (UDS 0x22 + OBD mode 09, μόνο ανάγνωση).
Ακατέργαστα δεδομένα: [`ecu-id.json`](ecu-id.json).

## Συμπέρασμα

**ECU κινητήρα: Bosch MSE 6.0, κατασκευή UAES** — επιβεβαιωμένο από την ίδια την ECU:

| Πεδίο | DID | Τιμή |
|---|---|---|
| Τύπος ECU (software number) | F188 | **MSE6.0** |
| Προμηθευτής συστήματος | F18A | **UAES** (United Automotive Electronic Systems — κοινοπραξία Bosch στην Κίνα) |
| Αριθμός hardware προμηθευτή | F192 | `BOS  0100F01R00D3KD` (πρόθεμα BOS = Bosch) |
| Αριθμός software προμηθευτή | F194 | `F05H00015L` |
| Έκδοση software προμηθευτή | F195 | `SW:1.00.00` |
| Έκδοση hardware | F191 / F193 | `HW:1.00.00` |
| Κωδικός ανταλλακτικού CFMOTO | F187 | `CF450MT` |
| Αναφορά CFMOTO (στο πεδίο «ημερομηνία προγραμματισμού») | F199 | `6AQV-001000-6400` |
| Calibration ID (CALID) | 09 04 | **`8811CF24503B6AQ2`** |
| Calibration verification number (CVN) | 09 06 | **`FBE14DDC`** |
| VIN | F190 / 09 02 | `LCEPESLGXT6001808` |
| Λοιπά | F189 / F196 / F197 | `ECM` / `20060110` / `0SQB` (hex `30 53 51 42`) |

Το `6AQV` εμφανίζεται στο F199, στο τέλος του CALID (`…6AQ2`) και στον κωδικό της δεύτερης μονάδας
— φαίνεται να είναι ο κωδικός πλατφόρμας του 450MT στην αρίθμηση CFMOTO (εκτίμηση, όχι επιβεβαιωμένο).

## Μονάδες που απαντούν

| Αίτημα → Απάντηση | Μονάδα | Απαντά σε OBD 7DF | Στοιχεία |
|---|---|---|---|
| 7E0 → 7E8 | **ECU κινητήρα (Bosch MSE6.0)** | ναι (01, 09) | βλ. παραπάνω· `10 01` → `50 01` |
| 7E1 → 7E9 | **Άγνωστη** | όχι | F187 `6AQV-6000`, F194 `88762`, F181 `10 00`, F186 `01`, VIN κενό (μηδενικά)· `10 01` → `50 01 00 32 01 F4` (P2 = 50 ms, P2* = 5 s) |

Σαρώθηκαν όλες οι φυσικές διευθύνσεις 11-bit **0x700–0x7F7** με `22 F190`· απάντησαν μόνο οι δύο.

**Η μονάδα 7E1 δεν αναγνωρίστηκε:** δεν δίνει όνομα/προμηθευτή, δεν υποστηρίζει `19 0A` (NRC 12)
ούτε απαντά στο OBD broadcast. Θα μπορούσε να είναι ABS, ταμπλό ή μονάδα κλειδιού/immobilizer —
χωρίς τεκμηρίωση CFMOTO δεν το ισχυρίζομαι.

**Δεν βρέθηκαν:** μονάδες σε 29-bit CAN (δεν σαρώθηκαν) ή μονάδες που απαντούν μόνο σε extended
session / μόνο σε άλλα DID. Το ABS συχνά βρίσκεται σε τέτοια διεύθυνση· η ανίχνευσή του θα απαιτούσε
σάρωση 29-bit (`18DAxxF1`), που δεν έγινε.

## Εύρημα κατά τη σάρωση: εκκρεμής κωδικός P0053

| Πηγή | Αποτέλεσμα |
|---|---|
| OBD mode 07 (εκκρεμείς) | **P0053** |
| OBD mode 03 / 0A | κανένας · MIL σβηστή |
| UDS `19 02 FF` (7E0) | P0053 status `0x26` (απέτυχε σε αυτόν τον κύκλο + εκκρεμής) · P0054 status `0x20` (απέτυχε κάποια στιγμή από το τελευταίο σβήσιμο) · P0111/P0112/P0113 status `0x50` (τεστ μη ολοκληρωμένο — όχι βλάβη) |

P0053 = αντίσταση θέρμανσης αισθητήρα λάμδα B1S1 εκτός ορίων· P0054 = το ίδιο για B1S2.
Δεν είναι ακόμα επιβεβαιωμένος κωδικός (η MIL δεν άναψε). Πρόταση: κανονική διαδρομή και
επανέλεγχος· αν επιβεβαιωθεί, μέτρηση αντίστασης θέρμανσης και έλεγχος φις/καλωδίων κοντά στην
εξάτμιση (βλ. βάση γνώσης της εφαρμογής, P0053).

## Μέθοδος (μόνο ανάγνωση)

- Ρυθμίσεις adapter: `ATSP6 ATCAF1 ATH1 ATCF700 ATCM700` (φίλτρο λήψης όλων των 0x7xx), flow control
  `ATFCSH<tx> ATFCSD300000 ATFCSM1`.
- Υπηρεσίες ECU: `01 00`, `09 02/04/06/0A`, `10 01` (default session), `22 F180…F19E`, `19 01 FF`, `19 02 FF`, `19 0A`.
- Όλες οι εντολές πέρασαν από τη whitelist (`tools/obd_safety.py`). Καμία εντολή εγγραφής,
  security access ή extended session.
