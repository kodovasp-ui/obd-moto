# Reflash / remap — έρευνα και σχέδιο (ΚΑΜΙΑ εγγραφή)

> Αυτό το έγγραφο είναι μόνο έρευνα. Ούτε η εφαρμογή ούτε τα εργαλεία του έργου γράφουν στην ECU.
> Οι πληροφορίες για εργαλεία/τιμές προέρχονται από σελίδες πωλητών (Νοέμβριος 2026) και πρέπει
> να επιβεβαιωθούν πριν από οποιαδήποτε αγορά.

## 1. Τι ECU έχουμε (επιβεβαιωμένο — `docs/ecu-id.md`)

| | |
|---|---|
| ECU | **Bosch MSE 6.0**, κατασκευή UAES (F188 = `MSE6.0`, F18A = `UAES`) |
| Μικροελεγκτής (κατά AutoTuner) | **SPC563M64** (NXP/ST Power Architecture) |
| Software προμηθευτή | `F05H00015L`, `SW:1.00.00` |
| Calibration ID / CVN | `8811CF24503B6AQ2` / `FBE14DDC` |
| Δίαυλος | CAN 11-bit 500 kbps, ECU σε 7E0/7E8 |

Σημείωση: το MotoFlasher αναφέρει **MSE9.0** σε ορισμένα μοντέλα 450 του 2025–2026 (σε bench).
Η δική μας μοτοσυκλέτα (μοντέλο 2026) δηλώνει **MSE6.0** — άρα ισχύουν τα παρακάτω για MSE6.0.
Πριν από οποιαδήποτε εργασία ξαναδιάβασε το ECU ID (σελίδα «ECU» της εφαρμογής).

## 3. Διαδικασία backup (αν γίνει ποτέ, από επαγγελματία)

1. **Καταγραφή πριν από οτιδήποτε:** ECU ID, CALID, CVN, SW number (εφαρμογή → ECU, ή `tools/ecu_id.py`),
   κωδικοί βλάβης, live καταγραφή αναφοράς (ζεστό ρελαντί + 2500 rpm). Αποθήκευσε το `docs/ecu-id.json`.
2. **Πλήρες backup μέσω bench** (όχι μόνο OBD): το OBD read σε πολλές ECU διαβάζει μόνο την
   περιοχή calibration· το bench δίνει πλήρη εικόνα (flash + δεδομένα/EEPROM, όπου υποστηρίζεται).
3. **Δύο αναγνώσεις, ίδιο hash:** διάβασε δύο φορές και σύγκρινε SHA-256· αν διαφέρουν, σταμάτα.
4. **Αποθήκευση σε 3 μέρη** (PC, cloud, USB) με όνομα που περιέχει VIN, CALID, CVN, ημερομηνία.
5. **Επαλήθευση επαναφοράς:** ο πάροχος πρέπει να μπορεί να γράψει πίσω το original και να
   επιβεβαιωθεί ότι το CVN επιστρέφει σε `FBE14DDC`.

## 4. Τροφοδοσία

- **Στη μοτοσυκλέτα (OBD):** σταθεροποιημένο τροφοδοτικό/φορτιστής σε λειτουργία «power supply»
  13,0–14,0 V, ≥ 5 A· όχι απλός φορτιστής (κυμάτωση) και όχι μόνο η μπαταρία. Η δική μας μέτρηση
  με σβηστό κινητήρα ήταν ~12,0 V — **πολύ χαμηλή για flash χωρίς εξωτερική τροφοδοσία.**
- **Bench:** εργαστηριακό τροφοδοτικό 12–13,5 V, όριο ρεύματος 2–3 A, σωστή γείωση, σταθερή
  τροφοδοσία του laptop (φορτιστής συνδεδεμένος, απενεργοποιημένος ύπνος/ενημερώσεις).
- Ποτέ διακοπή κατά την εγγραφή: διακοπή = πιθανό «τούβλο» (brick) που θέλει ανάκτηση σε bench/boot.

## 5. Κίνδυνοι

| Κίνδυνος | Σχόλιο |
|---|---|
| Brick ECU | Διακοπή ρεύματος/σύνδεσης κατά την εγγραφή. Με BLE dongle (όπως το δικό μας) **αδύνατο/ακατάλληλο** — τα εργαλεία flash χρησιμοποιούν δικό τους καλωδιακό interface. |
| Ανιχνευσιμότητα | Το **CVN αλλάζει** με κάθε τροποποίηση calibration και διαβάζεται από οποιοδήποτε OBD (mode 09 06) — και από αντιπρόσωπο/ΚΤΕΟ. Πολλές ECU κρατούν και μετρητή flash. |
| Immobilizer / δεύτερη μονάδα | Η μονάδα 7E1 (`6AQV-6000`) δεν αναγνωρίστηκε· αν συμμετέχει σε immobilizer, λάθος χειρισμός ECU μπορεί να ακινητοποιήσει τη μοτοσυκλέτα. |
| Ζημιά κινητήρα | Φτωχοί χάρτες / υπερβολική προπορεία σε καύσιμο χαμηλών οκτανίων → κρουστική καύση, υπερθέρμανση. |
| OBD II (Euro 5+) | Αλλαγές σε αισθητήρες/καταλύτη ή σε όρια ελέγχου μπορεί να ανάψουν MIL ή να αποτύχει η επιθεώρηση. |
| Δίπλωμα A2 | Το 450MT επιτρέπεται με A2 (≤ 35 kW, ≤ 0,2 kW/kg). Αύξηση ισχύος μπορεί να βγάλει τη μοτοσυκλέτα εκτός ορίων A2. |
| Ασφάλιση / μεταπώληση | Μη δηλωμένη τροποποίηση μπορεί να δημιουργήσει πρόβλημα σε ατύχημα· μειωμένη αξία μεταπώλησης. |
| Υπάρχον εύρημα | Εκκρεμής **P0053** (θέρμανση λάμδα). Πρώτα διάγνωση/αποκατάσταση, ποτέ tune πάνω σε ενεργή βλάβη. |

## 6. Εγγύηση

- Η μοτοσυκλέτα είναι μοντέλο 2026 — πιθανότατα εντός εργοστασιακής εγγύησης.
- Ο κανονισμός (ΕΕ) 461/2010 (block exemption) προστατεύει από απόρριψη εγγύησης **μόνο** επειδή
  έγινε σέρβις εκτός δικτύου ή μπήκαν μη γνήσια ανταλλακτικά· **δεν** καλύπτει ζημιά που προκάλεσε η
  τροποποίηση ([EUR-Lex 461/2010](https://eur-lex.europa.eu/eli/reg/2010/461/oj)).
- Λόγω CVN/μετρητή flash, η τροποποίηση συνήθως ανιχνεύεται ακόμα και μετά από επαναφορά.
- Πρακτικά: tune κατά τη διάρκεια της εγγύησης = αποδοχή ότι βλάβες κινητήρα/ηλεκτρονικών μπορεί
  να απορριφθούν. Ζήτα γραπτώς τη θέση του αντιπροσώπου CFMOTO πριν από οτιδήποτε.

## 7. Νομιμότητα στην ΕΕ (Euro 5+)

- **Κανονισμός (ΕΕ) 168/2013, άρθρο 20:** οι κατασκευαστές οφείλουν να ενσωματώνουν μέτρα κατά της
  επέμβασης (anti-tampering) στο σύστημα πρόωσης ώστε να μην αυξάνονται ροπή/ισχύς/τελική ταχύτητα
  πέρα από την έγκριση τύπου· μετά από τροποποίηση το όχημα πρέπει να εξακολουθεί να πληροί τις
  απαιτήσεις της κατηγορίας του ([EUR-Lex 168/2013](https://eur-lex.europa.eu/eli/reg/2013/168)).
- **Euro 5+ (Καν. 2019/129, εκτελεστικός 2020/239):** απαιτεί OBD II stage II για L3e· έλεγχος
  καταλύτη και αισθητήρων κατά τη χρήση ([EUR-Lex 2020/239](https://eur-lex.europa.eu/eli/reg_impl/2020/239/oj/eng/pdf)).
- Συνέπεια: ένα tune που αλλάζει ισχύ ή εκπομπές **χωρίς νέα έγκριση** κάνει το όχημα μη
  συμμορφούμενο για χρήση σε δημόσιο δρόμο. Γι' αυτό πολλοί πάροχοι το πουλούν «μόνο για πίστα».
- **Ελλάδα:** οι μοτοσυκλέτες > 125 cc περνούν ΚΤΕΟ (πρώτη φορά 4 χρόνια μετά την ταξινόμηση, μετά
  ανά 2 χρόνια). **Δεν βρέθηκε** τεκμηριωμένη πηγή για το πώς ελέγχεται/τιμωρείται το chip tuning
  ειδικά σε μοτοσυκλέτες — χρειάζεται επιβεβαίωση από ΚΤΕΟ ή νομικό.

## 8. Σύσταση

1. **Όχι remap τώρα:** εγγύηση σε ισχύ, εκκρεμής P0053, χαμηλή τάση μπαταρίας, νομικό ρίσκο για δρόμο,
   μικρό όφελος (λίγα hp).
2. Αν το κίνητρο είναι η απόκριση γκαζιού στις χαμηλές: πρώτα διάγνωση με την εφαρμογή (fuel trims,
   λάμδα, ρελαντί) και σέρβις σώματος πεταλούδας — συχνά αρκεί.
3. Αν αργότερα αποφασιστεί tune: μόνο από επαγγελματία με **bench backup** και τεκμηριωμένη υποστήριξη
   MSE6.0/450MT, μετά τη λήξη της εγγύησης, με γραπτή δυνατότητα επαναφοράς, και με επίγνωση ότι
   η χρήση σε δρόμο μπορεί να μην είναι νόμιμη.
4. Η εφαρμογή παραμένει **μόνο ανάγνωσης**· η σελίδα «ECU» δείχνει το ECU ID, ελέγχει αν άλλαξε το CVN
   (ένδειξη επέμβασης) και τι εργαλεία είναι γνωστά.
